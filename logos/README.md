# Logos

Put an Outlet's logo image here (PNG, JPG, or WebP) and reference it in `outlets.yaml`:

```yaml
The New York Times:
  logo: logos/nyt.png
```

The path is relative to the page. A logo is never found by filename; it only shows if `logo:` names it. It is fitted into a 460x52 box and drawn with no white chip, so pick one that suits the Outlet's Theme.
